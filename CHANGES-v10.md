# Amupys Website v10

## Change
- Dedicated app pages no longer repeat the app icon inside the large hero preview.
- The hero preview now uses a landscape feature graphic.
- Recommended image size: 1024x500.
- Each app has a separate `heroImage` field in `app-data.js`.
